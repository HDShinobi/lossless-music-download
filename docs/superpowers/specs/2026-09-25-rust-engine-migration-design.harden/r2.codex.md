[SEVERITY: major]
LENS: assumptions
LOCATION: §3.4 Coexistence flag; §3.5 Persisted data across the engine switch
ISSUE: Go and Rust A/B runs share the same profile even though Rust may migrate or write engine-private data that Go cannot read, so one Rust run can invalidate later Go runs and the rollback path during coexistence.
SUGGESTION: Use isolated profile snapshots or engine-specific data directories for A/B, and define the one-way canonical-profile cutover point; alternatively require and test bidirectional on-disk compatibility through phase 4.

[SEVERITY: major]

ISSUE: Fix 3 requires three separately wrapped LM-FORK sites but the registry contains one active Rust row, so the specified block-count equality can never pass.
SUGGESTION: Give all three blocks one logical fork ID and validate unique active IDs against registry rows, or create one registry row per counted block and align the success criterion accordingly.
